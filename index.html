Formula Reference

Beginner feedrate  = Neff × Chipload × RPM × Machine index
Advanced feedrate  = N × Chipload × RPM
RPM      ≈ (22 000 − Chipload × 30 000) × Machine index   [cap: 24 000]
Max DOC  = Machine DOC factor × Tool ∅ × Material DOC factor
  • Neff        = effective flutes: (actual flutes + 1) / 2
  • Chipload      = chip load per tooth (mm/tooth) — interpolated from table
  • RPM           = spindle rotation speed (rev/min)
  • Feedrate      = table movement speed (mm/min)
  • Machine index  = EVO 0.75 / PRO 0.90 / FAB 1.00 (feed & speed scaling)
  • Machine DOC   = EVO 0.5× / PRO 0.8× / FAB 1.0× (depth of cut scaling)
  • Material DOC  = Hardwood 0.9 / Softwood 1.0 / MDF 1.0 / Soft Plastic 0.8 / Hard Plastic 0.5 / Aluminium 0.25
