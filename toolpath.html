How To Use This

Stepover distance = Tool diameter × Stepover %
Passes = Pocket width / Stepover distance
Cut time = Toolpath length / Feed rate
  • Use a lower stepover for smoother surfaces and harder materials.
  • Use the feeds and speeds page to choose a safe starting feed rate.
  • The estimate assumes each pass travels the full pocket length.

Use this estimate as a planning aid only. Always verify toolpaths in CAM before cutting.
